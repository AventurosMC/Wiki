# Les Commandes

Voici la liste des commandes accessibles aux joueurs sur Aventuros.

*Les arguments marqués entre chevrons `< >` sont obligatoires, et ceux marqués entre crochets `[ ]` sont facultatifs.*

## Sur tous les serveurs

| Commande | Utilisation |
| -------- | ----------- |
| `/hub` | Vous téléporte au lobby de sélection entre les serveurs Faction et Mini-Jeux. |
| `/lobby` | Vous téléporte au lobby du serveur sur lequel vous êtes connecté. |
| `/msg <joueur> <message>` | Permet d'envoyer un message privé à un joueur (ne fonctionne pas inter-serveur). |
| `/changepw [nouveau mot de passe]` | Pour les joueurs qui se connectent avec un compte crack, permet de changer le mot de passe que vous avez à taper lors de la connexion au serveur. Si aucun mot de passe n'est entré après la commande, le serveur vous demandera de l'entrer directement dans le chat ensuite. |
| `/report <joueur> <raison>` | Permet de signaler un joueur au staff. |

## Sur le serveur Faction

| Commande | Utilisation |
| -------- | ----------- |
| `/spawn` | Permet de vous téléporter au spawn du monde où vous êtes. |
| `/faction`<br>`/minage` | Permettent de vous téléporter respectivement en monde faction et en monde minage. |
| `/home [nom]`<br>`/sethome [nom]`<br>`/delhome [nom]` | Permettent respectivement de se téléporter à un de vos homes, d'en placer un, ou d'en supprimer un. Par défaut, le nom utilisé est `home`. |
| `/tpa <joueur>`<br>`/tpahere <joueur>` | Permettent de demander une téléportation. La première demande à se téléporter à un joueur, la seconde demande à téléporter l'autre joueur à vous. |
| `/tpaccept [joueur]`<br>`/tpcancel [joueur]` | Permettent respectivement d'accepter une demande de téléportation, ou de la refuser. Vous devez spécifier un joueur si vous avez plusieurs demandes en attente. |
| `/tptoggle` | Permet d'activer ou de désactiver les demandes de téléportation vous impliquant. |
| `/suicide` | Permet de vous suicider (vous perdrez votre inventaire bien entendu). |
| `/aventurolag time` | Permet d'afficher le temps jusqu'au prochain AventuroLag. Vous pouvez aussi utiliser le module graphique, activable dans les options en jeu. |
| `/mail` | Ensemble de commandes pour envoyer des mails, des sortes de messages privés qui peuvent être envoyés à des joueurs déconnectés. Tapez `/mail help` en jeu pour obtenir plus d'aide. |
| `/money` | Permet d'afficher la quantité de monnaie que vous possédez sur votre compte. |
| `/pay <joueur> <quantité>` | Permet d'envoyer de l'argent à un autre joueur. |
| `/baltop` | Affiche le classement des joueurs les plus riches du serveur. |
| `/rewards` | Permet de récupérer les récompenses en attente. Elles incluent pour le moment les récompenses des [votes](https://aventuros.fr/voter/). |
